Day 11 - Pivot Tables and Dashboard

Topics Covered

1. Pivot Table Fundamentals

Learned the fundamentals of Pivot Tables and how they are used to summarize, analyze, and explore large datasets efficiently.

What is a Pivot Table?

A Pivot Table is an Excel tool used to quickly summarize and analyze data by organizing information into rows, columns, values, and filters.

Common Use Cases

* Summarizing sales data
* Analyzing employee data
* Comparing departments
* Analyzing product performance
* Finding totals and averages
* Identifying trends and patterns
* Creating interactive reports and dashboards

2. Creating and Understanding Pivot Tables

Practiced creating the first Pivot Table and learned the structure of its main fields:

 Row Field

Used to organize data into rows based on categories.

Column Field

Used to organize data across columns for comparison.

Value Field

Used to perform calculations such as:

* Sum
* Count
* Average
* Minimum
* Maximum

Filter Field

Used to filter the entire Pivot Table based on selected criteria.

3. Data Manipulation

Practiced manipulating Pivot Table data using:

* Grouping
* Filtering
* Sorting
* Changing value calculations
* Calculated Fields

Grouping

Used grouping to organize data into meaningful categories such as months, quarters, and years.

Filtering and Sorting

Used filters and sorting to focus on specific data and arrange results in a useful order.

Calculated Field

Learned how to create calculated fields in Pivot Tables to perform additional calculations using existing data fields.

## 4. Interactivity and Visualization

Slicers

Used slicers to create interactive buttons that allow users to filter Pivot Table data quickly.

Timelines

Used Timelines to filter date-based Pivot Table data interactively by periods such as months, quarters, or years.
