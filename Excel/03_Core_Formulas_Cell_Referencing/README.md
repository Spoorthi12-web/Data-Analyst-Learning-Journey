Day 03 - Core Formulas and Cell Referencing

Overview

In this session, I learned how to use Excel formulas, common functions, and different types of cell references to perform calculations and manage data efficiently.

Topics Covered

1. Arithmetic Operators

- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Exponential (^)

2. Common Functions
- SUM()
- AVERAGE()
- MIN()
- MAX()
- ROUND()

3. Cell Referencing
- Relative Cell Reference
- Absolute Cell Reference
- Mixed Cell Reference

4. Ranges and Named Ranges
- Selecting and working with cell ranges
- Creating Named Ranges
- Using Named Ranges in formulas
