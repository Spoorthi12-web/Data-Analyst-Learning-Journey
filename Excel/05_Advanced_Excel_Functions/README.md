Day 05 - Advanced Excel Functions

Overview

In this session, I learned advanced Excel functions, including Logical Functions and Text Functions, to perform conditional calculations and manipulate text data efficiently.

Topics Covered

1. Logical Functions

IF Function
Learned how to use the IF function to perform logical tests and return different results based on conditions.

Syntax:

IF(logical_test, value_if_true, value_if_false)

>Example:

IF(Salary>50000,"Yes","No")

AND Function
Used the AND function when multiple conditions need to be satisfied.

>Example:

IF(AND(Salary>50000,Years>5),"Bonus","No Bonus")

OR Function
Learned how to check whether at least one of multiple conditions is satisfied.

Hands-on Demo - Logical Functions

Created a practice exercise using IF, AND, and OR functions to evaluate employee conditions and determine bonus eligibility.



2. Text Functions

LEFT and RIGHT
- LEFT() - Extracts characters from the beginning of a text
- RIGHT() - Extracts characters from the end of a text

FIND
Used to find the position of specific text or characters within a cell.

LEN
Used to count the number of characters in a text string.

CONCAT
Used to combine text from multiple cells or text strings.

TEXTJOIN
Used to combine text from multiple cells with a specified delimiter.

Learning Outcome

Learned how to use Logical and Text Functions in Excel to perform conditional analysis, extract and manipulate text, and build more efficient formulas.
