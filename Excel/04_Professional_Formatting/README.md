 Day 04 - Professional Formatting

Overview

In this session, I learned professional Excel formatting techniques to make data more organized, readable, and visually presentable.

Topics Covered

1. Fonts
- Changing font type and size
- Bold, Italic, and Underline
- Improving text appearance

2. Colors and Borders
- Applying cell colors
- Using borders
- Highlighting important data

3. Number Formats
- Number formatting
- Currency formatting
- Percentage formatting
- Date formatting

4. Dynamic Row and Column Adjustment
- Adjusting row height
- Adjusting column width
- AutoFit rows and columns

Hands-on Project

->Professional Formatting Practice

Applied professional formatting techniques to an Excel dataset to improve its readability, structure, and presentation.

Learning Outcome

Learned how to professionally format Excel data using fonts, colors, borders, number formats, and dynamic row and column adjustments.
