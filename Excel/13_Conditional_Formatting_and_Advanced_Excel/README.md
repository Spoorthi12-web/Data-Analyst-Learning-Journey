Day 13 - Conditional Formatting and Advanced Excel Features

Topics Covered

1. Conditional Formatting

Learned how to use Conditional Formatting to highlight important information and identify patterns, trends, and exceptions in data.

Practiced:

* Highlighting cells based on conditions
* Data Bars
* Color Scales
* Icon Sets
* Duplicate values
* Rule-based formatting

2. Quick Analysis Tool

Learned how to use the **Quick Analysis Tool** to quickly analyze and visualize selected data using:

* Formatting
* Charts
* Totals
* Tables
* Sparklines

 3. Tables for Dynamic Ranges

Learned how to convert data into Excel Tables to create dynamic ranges that automatically expand when new data is added.

4. Advanced Sorting and Filtering

Practiced advanced methods of organizing and analyzing data using:

* Multi-level sorting
* Custom sorting
* Advanced filtering
* Filtering based on multiple conditions

5. Subtotals and Outlines

Learned how to use **Subtotals** and **Outlines** to organize and summarize large datasets.

Practiced:

* Creating subtotals
* Grouping data
* Expanding and collapsing data sections
* Creating structured summaries

Advanced Excel Features

### 6. Dynamic Named Ranges

Learned how to create named ranges that can dynamically adjust when data is added or removed.

7. What-If Analysis

Learned how to analyze different possible outcomes by changing input values.

Practiced:

* Scenario analysis
* Goal Seek

8. Form Controls

Learned the basics of Excel Form Controls for creating interactive worksheets.

Examples include:

* Check Boxes
* Option Buttons
* Drop-down controls
* Scroll Bars

9. Interactive Elements

Practiced combining Excel features to create more interactive and user-friendly reports and analysis sheets.

10. Hands-On Practice

Applied the concepts to sample datasets by:

* Highlighting important values using Conditional Formatting
* Creating dynamic Excel Tables
* Performing advanced sorting and filtering
* Creating subtotals and outlines
* Creating dynamic named ranges
* Performing What-If Analysis
* Exploring Form Controls
* Adding interactive elements
