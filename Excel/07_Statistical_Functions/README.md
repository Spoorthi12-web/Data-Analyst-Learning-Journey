 Day 7 - Statistical Functions

Topics Covered

COUNT Family

* COUNT– Counts cells containing numbers.
* COUNTA – Counts non-empty cells.
* COUNTIF – Counts cells based on a single criterion.
* COUNTIFS – Counts cells based on multiple criteria.

SUMIF / SUMIFS

* SUMIF– Sums values based on a single criterion.
* SUMIFS– Sums values based on multiple criteria.

AVERAGEIF / AVERAGEIFS

* AVERAGEIF – Calculates the average based on a single criterion.
* AVERAGEIFS – Calculates the average based on multiple criteria.

Practical Practice

* Conditional summing
* Multiple-condition summing
* Conditional averaging
* Multiple-condition averaging
