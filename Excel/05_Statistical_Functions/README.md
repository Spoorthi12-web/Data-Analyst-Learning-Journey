 07 Statistical Functions

Topics Covered

In this practice, I learned and practiced Excel Statistical Functions used for counting, summing, and calculating averages based on specific criteria.

### COUNT Family

* **COUNT** – Counts cells containing numbers.
* **COUNTA** – Counts non-empty cells.
* **COUNTIF** – Counts cells that meet a single criterion.
* **COUNTIFS** – Counts cells that meet multiple criteria.

### SUMIF / SUMIFS

* **SUMIF** – Sums values that meet a single criterion.
* **SUMIFS** – Sums values that meet multiple criteria.

### AVERAGEIF / AVERAGEIFS

* **AVERAGEIF** – Calculates the average of values that meet a single criterion.
* **AVERAGEIFS** – Calculates the average of values that meet multiple criteria.

Practical Examples

I practiced these functions using employee-related datasets to answer questions such as:

* Counting the number of employees.
* Counting employees based on department.
* Counting employees based on multiple conditions.
* Calculating total salary based on department.
* Calculating total salary based on multiple conditions.
* Finding average salary based on department.
* Finding average salary based on multiple conditions.
